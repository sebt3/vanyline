# vanyline

Chat vanyline dans la sidebar secondaire de code-server/VS Code, propulsé par
le binaire local `vanyline serve --stdio` (téléchargé et mis à jour
automatiquement depuis les releases GitHub, SHA256 vérifié).

Installation et procédure de test : voir `docs/ext-install.md` du dépôt
[sebt3/vanyline](https://github.com/sebt3/vanyline).
