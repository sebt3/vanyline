# vanyline frontend

IDE web de vanyline. Vue 3 + Vite.

- Coquille dockable : [dockview-vue](https://dockview.dev)
- Éditeur : [CodeMirror 6](https://codemirror.net)
- Terminal : [xterm.js](https://xtermjs.org)
- Arbre de fichiers : [Element Plus](https://element-plus.org) (`el-tree`, restylé)
- Barre de menu / vue Configuration : [Reka UI](https://reka-ui.com) (`Menubar`, `Tabs`, headless)
- Chat : [vue-advanced-chat](https://github.com/advanced-chat/vue-advanced-chat) — theming non résolu, voir `docs/features/frontend-ui-shell.md`

## Commandes

```bash
npm run dev       # serveur de dev
npm run build     # build production (type-check + vite build)
npm run check     # type-check seul
npm run test      # vitest run
```
